参与贡献

MIT 协议，欢迎提交 issue 与 PR。

环境

需要 Node >= 24。项目不使用打包器，TypeScript 由 Node 直接执行：

npm install
npm run typecheck    # tsc -p tsconfig.json
npm test             # node --test

提交前检查

  1. npm run typecheck 无错误（已开启 noUncheckedIndexedAccess）。
  2. npm test 全部通过，且新增逻辑有对应测试。
  3. 不提交运行时数据：*.db、runtime-config.json、安装包等已由 .gitignore 排除。

代码约定

  • 引擎层不引入 UI 框架；系统交互一律走可注入接口。
  • 注释解释「为什么这样设计」，不逐行复述代码。
  • 文件写入采用「临时文件 + rename」保证原子性。
  • 危险操作（注册表写入/删除）默认 dryRun，并要求显式确认串。

测试约定

测试用 node --test，按包分目录：packages/*/test/*.test.ts。 系统副作用一律替换为内存实现（InMemoryRegClient、fakeRunner、 MemoryAutoStartBackend），因此无需真实注册表与安装包即可运行。

新增安装器类型时，请补一条矩阵用例：校验执行计划（程序名与参数）、 成功回读到版本号、失败时按开关清理安装包。

范围红线

以下内容不属于本项目范围，请勿以任何形式引入：

  • 终端管控：行为采集、Web 中间人、锁屏、远程桌面、驱动级进程拦截、静默保活
  • 绕过授权、破解或绕过许可校验的实现
  • 任何来源不明或未经授权的代码还原产物
  • 第三方产品的二进制、素材与图标数据

贡献的功能请以独立设计方式实现：可参考公开文档与通用工程实践， 但不得复制他人实现的代码或资源。
